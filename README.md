# YouTube Audio Downloader

This script allows you to download audio from a YouTube video and save it as an MP3 file on your desktop.

## Requirements
- Python installed on your system
- `yt-dlp` installed (`pip install yt-dlp`)

## How to Use
1. Run the script.
2. Enter the YouTube video URL when prompted.
3. The audio file will be downloaded and saved on your desktop.
